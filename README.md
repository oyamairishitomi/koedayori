# こえだより

遠方に住む祖父母の「今日の声」を、家族の思い出として残す見守りアプリ

## 📖 概要

こえだよりは、遠方に住む高齢の祖父母がいる家族向けの見守りアプリです。

離れて暮らす祖父母の日常の声を、家族の記録として残せないか——そんな課題を解決するために生まれました。

一般的な電話での安否確認サービスとは異なり、こえだよりは**トークテーマに沿って発信された声を記録として蓄積**し、家族がいつでも聞き返せる点が特徴です。単なる「今無事かどうか」の確認にとどまらず、日々の何気ない声そのものが、かけがえのない思い出として積み重なっていきます。

## 🎯 解決したい課題

- 遠方に住む祖父母の日常の声を、思い出として残す手段がない
- 電話での安否確認は「無事かどうか」の一瞬の確認で終わってしまい、記録が残らない
- 高齢者にとって、ログインやID・パスワードの管理はハードルが高い

## ✨ 特徴

### 祖父母側:とにかくシンプル

- 毎日のログイン不要
- ID・パスワードの入力不要
- ホーム画面のアイコンをワンタップするだけで音声投稿が完了

### 家族側:自然に安否確認できる

- 投稿された声はいつでも聞き返せる
- トークテーマに沿った声が記録として蓄積されていく
- 「無事を確認する」のではなく、「声を聞いて自然と安心する」体験

## 🔊 こんな課題を解決します

| 従来の電話での安否確認   | こえだより                           |
| ------------------------ | ------------------------------------ |
| その場限りの確認で終わる | 声が記録として蓄積される             |
| 用件がないとかけづらい   | トークテーマがあるので話しやすい     |
| 忙しいと聞き逃してしまう | いつでも好きなタイミングで聞き返せる |

## 🛠 技術スタック

- フロントエンド: DaisyUI, Tailwind CSS
- バックエンド: Ruby on Rails
- インフラ: Conoha VPS, Cloudfrare
- その他: Stimulus

## 🚀 セットアップ

### 動作環境

- Ruby 4.0.5
- Rails 8.1.3.1
- PostgreSQL
- Node.js / npm(Tailwind CSSのDaisyUIプラグイン解決に使用)

### 動かし方

```bash
# リポジトリをクローン
git clone https://github.com/oyamairishitomi/koedayori.git
cd koedayori

# 依存関係のインストール・DB準備・開発サーバー起動をまとめて実行
bin/setup
```

`bin/setup`は以下を自動で行います。

1. `bundle install`(gemのインストール)
2. `bin/rails db:prepare`(データベースの作成・マイグレーション)
3. `bin/dev`の起動(Rails + Tailwindのビルドを同時に立ち上げ)

起動後は [http://localhost:3000](http://localhost:3000) でアクセスできます。

> ⚠️ `config/master.key`(暗号化された認証情報の復号キー)はリポジトリに含まれていません。ローカルで動かす場合は別途鍵を共有してもらってください。

## 📱 使い方

1. 祖父母は毎日、ホーム画面のアイコンをワンタップして音声を録音・投稿
2. 投稿された声は家族のアプリに届き、いつでも聞き返せる
3. トークテーマに沿った声が記録として蓄積され、日々の思い出として残っていく
